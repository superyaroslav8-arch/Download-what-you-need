# Скачай, что надо!

Современный каталог приложений и игр для **iPhone**, **iPad** и **Android**.

## Возможности

- 🔎 Быстрый поиск по названию, разработчику и категориям
- 📱 Автоопределение устройства (iPhone / iPad / Android)
- 🗂 Категории: игры, мессенджеры, соцсети, ИИ, музыка, видео и др.
- ⭐ Избранное (сохраняется в браузере)
- 📥 История просмотров
- 🌙 Светлая / тёмная тема
- ✅ Только реальные ссылки на App Store, Google Play, веб-версии и официальные сайты
- 🚫 Без фейковых кнопок и пиратского контента

## Как открыть

Откройте `index.html` в браузере или разместите на любом статическом хостинге / GitHub Pages.

### GitHub Pages

1. Settings → Pages → Source: Deploy from a branch
2. Branch: `main` / root
3. Сайт будет доступен по адресу:  
   `https://superyaroslav8-arch.github.io/skachay-chto-nado/`

## Структура

```
├── index.html      # Главная страница (SPA)
├── css/style.css   # Стили + тёмная тема
├── js/
│   ├── data.js     # Каталог реальных приложений
│   └── app.js      # Логика: поиск, роутинг, избранное, устройство
└── README.md
```

## Добавление приложений

Редактируйте массив `APPS` в `js/data.js`.  
Каждое приложение — объект с полями:

- `id`, `name`, `developer`, `category`, `description`
- `platforms`: `["ios", "android", "web"]`
- `links`: `{ ios, android, web, official }`
- `free`, `popular`, `rating` (только если есть достоверный источник)

После добавления перезагрузите страницу — HTML менять не нужно.

## Важно

- Сайт полностью бесплатный для пользователя.
- Мы не распространяем платные приложения бесплатно.
- Все ссылки ведут на официальные магазины или сайты разработчиков.
